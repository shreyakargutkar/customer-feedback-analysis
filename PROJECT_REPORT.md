# Customer Feedback & Sentiment Analysis Platform - Project Report

## 🎯 **Overview**
Modern Next.js web application for collecting, analyzing, and visualizing customer feedback across multiple outlets. Features AI-powered sentiment analysis, keyword detection, and actionable insights.

**Tech Stack**:
- **Frontend**: Next.js 14+, TypeScript, TailwindCSS (inline styles), Chart.js, React Hook Form
- **Backend**: Supabase (PostgreSQL + Auth), Serverless API routes
- **AI/ML**: HuggingFace (Twitter RoBERTa sentiment), Custom keyword-based analysis
- **Auth**: Supabase Auth (email/password)

**Core Features**:
- Multi-role auth (admin/employee)
- Feedback submission with star ratings
- Real-time dashboard analytics (pie/bar charts)
- Outlet-based filtering
- Sentiment classification (Favourable/Unfavourable/Neutral)
- Service improvement recommendations

## 💬 **Feedback Workflow**
1. **Submit** (`add-comment.tsx` → `/api/add-comment`):
   ```
   Form → POST {guest_name, outlet_id, rating, comment_text, phone, email}
   ↓
   Keyword scan (keywords table) → sentiment: Favourable/Unfavourable/Neutral
   ↓ (fallback)
   HuggingFace API → sentiment classification
   ↓
   INSERT comments table: sentiment, sentiment_reason, sentiment_confidence
   ```

2. **View/Analyze** (`dashboard.tsx`):
   ```
   supabase.from('comments').select('id,created_at,sentiment,...').limit(1000)
   ↓
   Client-side: pie chart (sentiment %) + bar (7-day trend)
   ↓
   Outlet filter → stats + AI insights (issue detection)
   ```

**Note**: Charts filter by `selectedOutlet`. **Fix applied**: Defaults to ALL outlets.

### Sentiment Engine (`add-comment.ts`)
```
1. Keywords table scan (positive/negative)
2. Match count → Favourable/Unfavourable/Neutral
3. Fallback: HuggingFace Twitter-RoBERTa
```

### Data Schema (Supabase)
```
comments: id, guest_name, outlet_id, rating(TEXT), comment_text, sentiment, created_at
profiles: id, role (admin/employee)
keywords: keyword, polarity (positive/negative)
outlets: id, outlet_name
```
